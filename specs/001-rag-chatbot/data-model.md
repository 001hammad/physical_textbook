# Data Model: RAG Chatbot for Physical AI & Humanoid Robotics Book

## Core Entities

### BookContent
- **id**: string - Unique identifier for each book section/chapter
- **title**: string - Title of the section/chapter
- **content**: string - Full text content of the section
- **embedding**: list[float] - Vector representation of the content (from Cohere)
- **metadata**: dict - Additional information like chapter number, section hierarchy

### UserQuery
- **query_id**: string - Unique identifier for the query session
- **question**: string - The user's question about the book
- **selected_text**: string (optional) - Text selected by user for selected-text mode
- **mode**: string - Interaction mode ("normal" or "selected-text")
- **timestamp**: datetime - When the query was submitted

### RetrievedContext
- **context_id**: string - Unique identifier for the retrieved context
- **content**: string - The relevant book content retrieved from Qdrant
- **similarity_score**: float - Semantic similarity score (0.0-1.0)
- **source_id**: string - Reference to the original book content ID
- **retrieval_metadata**: dict - Additional metadata about the retrieval

### AgentResponse
- **response_id**: string - Unique identifier for the response
- **query_id**: string - Reference to the original query
- **answer**: string - The final answer generated by the agent
- **sources**: list[string] - List of book content IDs used to generate the answer
- **confidence**: float - Confidence level in the response (0.0-1.0)
- **timestamp**: datetime - When the response was generated

### ChatSession
- **session_id**: string - Unique identifier for the chat session
- **user_queries**: list[UserQuery] - List of queries in the session
- **responses**: list[AgentResponse] - List of responses in the session
- **created_at**: datetime - When the session was created
- **last_accessed**: datetime - When the session was last accessed

## Validation Rules

### BookContent Validation
- Content must not be empty
- ID must be unique across all book content
- Embedding must have the correct dimension for the embedding model used

### UserQuery Validation
- Question must not be empty in normal mode
- Selected text must not be empty in selected-text mode
- Mode must be either "normal" or "selected-text"

### RetrievedContext Validation
- Similarity score must be between 0.0 and 1.0
- Content must not be empty
- Source ID must reference a valid BookContent item

### AgentResponse Validation
- Answer must not be empty when content can be derived from book
- Sources must reference valid BookContent items
- Confidence must be between 0.0 and 1.0

## State Transitions

### Query Processing Flow
1. **UserQuery Created** → Query is received and validated
2. **Context Retrieved** → Relevant book content is retrieved from Qdrant
3. **Response Generated** → Agent generates answer based on retrieved context
4. **Response Returned** → Answer is sent back to user with source references

### Mode-Specific Processing
- **Normal Mode**: UserQuery → Retrieve from Qdrant → Generate Response
- **Selected-Text Mode**: UserQuery → Bypass Qdrant → Generate Response from selected text only
