# Content Filler Skill

## Instructions
1. Read the outline file
2. For each section, add 2-4 clear sentences
3. Use simple language suitable for students
4. Add fun or real-life examples where possible
5. Keep Markdown structure intact
6. Output filled content and save as new file

## Style
- Active voice
- Short paragraphs
- Educational but engaging

## Example
Input: ## What are Sensors?
Output: ## What are Sensors?
Sensors are like the eyes and ears of a robot. They detect light, sound, touch, and distance. For example, a camera sensor helps the robot "see" objects.
